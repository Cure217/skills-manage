# UE 教学视频生产管线参考

本文件用于给 `ue-doc-to-video` Skill 提供更具体的执行参考。

## 推荐生产流程

### 1. 文档理解

输入：

- 产品文档
- 教程文档
- 设计稿
- API / 功能说明
- 会议纪要

输出：

- 视频目标
- 受众画像
- 前置知识
- 章节拆分

### 2. 教学设计

建议按以下顺序组织：

1. 开场结果预览
2. 环境与前置准备
3. 主体步骤
4. 常见错误与修复
5. 总结与下一步

## Unreal Engine 制作建议

### 编辑器教学

优先使用：

- 屏幕录制
- 鼠标高亮
- 快捷键提示
- 关键区域放大

### 场景 / 动画演示

优先使用：

- `Sequencer`
- `Movie Render Queue`

适合：

- 镜头运动
- 动画演示
- 高质量结果镜头

## 推荐镜头类型

### A. 结果镜头

- 展示最终效果
- 用来增强用户观看动机

### B. 操作镜头

- 展示具体菜单、按钮、节点、参数

### C. 对比镜头

- 修复前 / 修复后
- 配置前 / 配置后
- 错误 / 正确

### D. 总结镜头

- 收尾复盘
- 给下一步建议

## 推荐内容结构

对于新手教程，建议每章控制为：

- 1 个核心目标
- 1 个可见结果
- 1～3 个关键动作
- 1 个常见坑提醒

## 外部工具建议

### 配音

- ElevenLabs
- 真实录音

### 字幕

- `subtitle.srt`
- 剪辑软件导入
- `ffmpeg` 烧录

### 动画 / 结构化排版

- Remotion
- Premiere / CapCut / Resolve

## 质量检查清单

- 是否一上来就告诉用户“最终效果”
- 是否明确受众与前置条件
- 是否每章只解决一个核心问题
- 是否给出中间结果和最终结果
- 是否提醒常见坑
- 是否给出补录点与风险点

## 注意

- 如果没有真实 UE 项目，默认不要承诺成片，只生成可执行制作包
- 如果项目仍在变动，优先生成“脚本包 + 分镜 + 资产清单”，减少返工

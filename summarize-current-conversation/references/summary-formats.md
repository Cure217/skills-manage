# Summary Formats

根据用户语气和目标，优先选用下面三种模板之一。

## 快速版

- 当前目标：
- 当前结论：
- 下一步：

适用：用户只想快速回顾，或准备继续当前任务。

## 标准版

- 摘要范围：基于当前可见上下文
- 当前目标：
- 关键结论：
- 已完成：
- 待确认 / 阻塞：
- 下一步：

适用：默认模式；适合多数“总结一下当前对话”的请求。

## 交接版

- 背景：
- 用户要求：
- 关键约束：
- 已做工作：
- 重要文件 / 命令 / 结果：
- 剩余事项：
- 建议接手顺序：

适用：准备换上下文、换人接手，或为后续继续执行做交接。

## 编码对话补充项

如果对话明显是编码、排障或自动化执行任务，在标准版或交接版里额外补：

- 已修改文件：
- 已运行验证：
- 未运行验证：
- 风险 / 阻塞：

# 输出模板

## 1. 简版

适合用户只想快速判断“值不值得继续看”。

建议结构：

- 一句话总结
- 3-5 条核心要点
- 适合谁看

## 2. 标准版

默认推荐使用。

建议结构：

- 一句话总结
- 核心观点
- 结构拆解
- 关键细节 / 数据 / 案例
- 适合谁看
- 可执行启发

## 3. 深度版

适合做分享、复盘或研究输入。

建议结构：

- 文章主题与背景
- 核心观点拆解
- 论证链路 / 框架
- 关键事实、案例、数据
- 作者可能的立场与局限
- 对业务 / 学习 / 实践的启发

## 4. 改写版

适合用户明确要求“公众号风格整理稿 / 长文改写版”。

建议要求：

- 保持原文主旨，不虚构新观点
- 强化标题、小节、过渡和阅读节奏
- 明确说明“这是整理改写版，不是逐字稿”

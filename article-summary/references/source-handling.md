# 来源处理建议

## 网页文章

- 优先保留：标题、作者、发布时间、来源站点、正文
- 尽量排除：导航栏、推荐阅读、评论区、页脚版权信息
- 如果正文抓取不完整，明确写“基于可见正文 / 摘录”

## Markdown / TXT

- 可直接读取正文
- 如果内容很长，优先提炼章节结构再总结

## PDF / DOCX / HTML

- 可结合现有 Skill 使用：
  - `markdown-converter`
  - `pdf`
  - `docx`
- 先把文件转换为可读文本，再做总结，避免直接基于格式噪音输出

## 用户手动粘贴片段

- 这类情况默认按“片段总结”处理
- 不要暗示已经看过全文
- 若用户想要更完整结果，提示其提供全文、文件或 URL

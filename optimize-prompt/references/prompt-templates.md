## Codex / Claude Code 模板

请直接在当前工作区完成以下任务。

【任务目标】
[明确要修复、实现、排查或修改什么]

【执行范围】
- 先检查相关文件、配置、模板、脚本或报错信息
- 只修改与任务直接相关的文件
- 优先做最小必要修改

【执行要求】
- 优先定位根因，不做表面修补
- 如果能直接修改并验证，就直接执行
- 如果存在环境限制、权限问题或依赖缺失，明确说明阻塞点
- 区分“文件真实问题”和“终端/工具显示问题”

【验证要求】
- 说明你如何验证修改有效
- 如果运行了命令，记录关键结果
- 如果无法完整验证，说明原因和剩余风险

【输出格式】
1. 问题定位
2. 根因分析
3. 修改内容
4. 修改的文件
5. 验证结果
6. 剩余风险（如有）

## Claude Code 加强版模板

请以 `Claude Code` 可直接执行的方式完成任务。

【任务目标】
[明确要完成的代码或排障任务]

【要求】
- 先阅读相关代码、文件和报错，再开始修改
- 优先解决根因，不做大范围无关重构
- 保持改动精简、可解释、可验证
- 如果被权限、依赖或环境问题阻塞，明确说明

【输出格式】
- 结论
- 修改内容
- 相关文件
- 验证结果
- 阻塞或风险
